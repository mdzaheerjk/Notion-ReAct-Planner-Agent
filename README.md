# Notion-ReAct-Planner-Agent
The Notion ReAct Planner Agent is an AI daily planning system using the ReAct (Reason + Act) architecture, integrated with Notion. It understands intent, breaks natural language into steps, and executes actions via Notion APIs and external tools to manage tasks, notes, and schedules.
